Proposal제안

Playful words as content tokens재치 있는 말을 콘텐츠 토큰으로

Minsik decided “a little playful”: toasts, empty states, loading lines, a few titles and celebrations. Today the only puns are typed straight into four screens, so nobody can change one in one place, cats get “Paw-fect!”, and there's no way to turn them off. Tokens fix all three.민식님 결정은 “살짝 재치 있게”: 토스트, 빈 화면, 로딩 문구, 일부 제목과 축하. 지금은 말장난이 네 화면에 직접 쓰여 있어서 한 곳에서 바꿀 수 없고, 고양이도 “Paw-fect!”를 받고, 끌 방법이 없어요. 토큰이 셋 다 해결해요.

1 · One file of words1 · 단어 파일 하나frontend/content/words.ts: each line has a key, the surface it may appear on, and three versions: plain, dog and cat.frontend/content/words.ts: 줄마다 키, 나올 수 있는 자리, 세 가지 버전(기본, 강아지, 고양이).
2 · One hook picks2 · 훅 하나가 고름useWords() returns w(key, {{ pet }}): the plain line when Playful words is off or no single pet is in view, else the dog or cat line for that pet.useWords()가 w(key, {{ pet }})를 돌려줘요: 재치 있는 말이 꺼져 있거나 펫이 하나가 아니면 기본, 아니면 그 펫의 강아지/고양이 버전.
3 · A switch in Settings3 · 설정의 스위치“Playful words”, on by default. Kept on the device first (no backend change); it can move to the account with the notification switches later.“Playful words”, 기본 켜짐. 우선 기기에 저장(백엔드 변경 없음); 나중에 알림 스위치처럼 계정으로 옮길 수 있어요.
4 · Never playful4 · 절대 재치 금지The type only allows tokens on toasts, empty states, loading, titles, celebrations and notices, so safety, money, agreements, errors and buttons can't get a pun by accident.타입이 토스트, 빈 화면, 로딩, 제목, 축하, 알림에만 토큰을 허용해서 안전, 돈, 동의, 오류, 버튼에는 실수로도 말장난이 못 들어가요.
// frontend/content/words.ts
export const WORDS = {
  stickerSaved: { on: "toast", plain: "Saved to {pet}'s stickers",
    dog: "Paw-fect! Saved to {pet}'s stickers", cat: "Purr-fect! Saved to {pet}'s stickers" },
  emptyDiary:   { on: "empty", plain: "No page yet. Today's page comes tonight",
    dog: "The diary's still napping. Today's page comes tonight",
    cat: "The diary's still curled up. Today's page comes tonight" },
  // …
} satisfies Record<string, Word>;

// in a screen
const w = useWords();
toast.show(w("stickerSaved", { pet }));   // plain when Playful words is off
