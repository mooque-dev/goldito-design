The model lines, word for word모델 설명, 그대로

About 25 seconds. Every version uses it: over the AI shots in A and B, as its own scene in C. Model names are exactly as in the README.약 25초. 모든 버전에 들어가요: A와 B는 AI 장면 위에, C는 따로 한 장면으로. 모델 이름은 README 그대로.

"Every AI call in Goldito runs on Nebius Token Factory, from our backend. NVIDIA Nemotron does the thinking and the writing: Nemotron 3 Nano drafts the sitter's reply in about three seconds, Nemotron 3 Super turns a care note into a timed checklist, writes the daily note and the pet's Life Record, and Nemotron 3 Ultra checks treat labels for allergens, because safety gets the strongest model. A vision model on Token Factory, MiniCPM-V 4.5, reads the photos, and Qwen3 Embedding lets the next sitter's reply remember the pet. Prices, dates and entry codes never come from a model: the server supplies them."

Model IDs, for the on-screen card: nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B · nvidia/nemotron-3-super-120b-a12b · nvidia/Nemotron-3-Ultra-550b-a55b · openbmb/MiniCPM-V-4_5 · Qwen/Qwen3-Embedding-8B

Recording촬영

Before Minsik hits record촬영 전에

  1. Wake the backend a minute before: the free plan sleeps, and the first request takes 30 to 50 s.
  2. Reset the demo set (Profile → Demo tools) so Robert and Chloe start the stay fresh; record on the default Chloe set.
  3. One clip per frame, 2 to 3 s of stillness at each end so the edit has room.
  4. Phone or phone frame only: 402 × 874, no browser chrome, no desktop. For version B, open ?view=split on a wide window.
  1. Hide the cursor or keep it still; taps should look like a finger (the frame already turns clicks into taps).
  2. Record the voiceover separately, in a quiet room, from the lines in each frame; the edit times the shots to it.
  3. Captions on for every spoken line (judges often watch muted).
  4. Export 1080 × 1920 or 1920 × 1080 with the phone centred; upload public to YouTube; paste the link in the README and on Devpost.
