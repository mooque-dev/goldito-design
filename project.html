    Three ways to push푸시하는 세 가지 방법

    A · Ask meA · 저에게 부탁

    Safest가장 안전

    Say what to push. I show you exactly what will go out first, then push and send the link.무엇을 올릴지 말해 주세요. 나갈 내용을 먼저 보여 드리고, 푸시한 뒤 링크를 드려요.

    “Push the stickers as a PR for #114”“스티커를 #114용 PR로 올려줘”
    1. I list the files, sizes and the commit message.파일, 크기, 커밋 메시지를 보여 드려요.
    2. I check for secrets (Minsik's keys never leave your Mac).비밀값을 확인해요 (민식 님 키는 맥 밖으로 안 나가요).
    3. You say “push”. I push, open the PR and link the ticket.“push”라고 하시면 푸시하고 PR을 열고 티켓을 연결해요.

    B · In the browserB · 브라우저에서

    Best for images이미지에 최적

    No installs. Good for stickers, icons and photos: files you drop into one folder.설치 없음. 스티커, 아이콘, 사진처럼 한 폴더에 넣는 파일에 좋아요.

    1. Open the folder on github.com, e.g. frontend/assets/stickers ↗.github.com에서 폴더를 여세요. 예: frontend/assets/stickers ↗.
    2. Add file → Upload files, drop the PNGs (same names replace the old ones).Add file → Upload files, PNG를 끌어다 놓기 (같은 이름이면 기존 파일을 바꿔요).
    3. Message: feat: add the Goldito sticker set.메시지: feat: add the Goldito sticker set.
    4. Pick Create a new branch… and start a pull request, name it design/sticker-set.Create a new branch… and start a pull request를 고르고 이름은 design/sticker-set.
    5. In the PR text write Closes #114, add a screenshot, Create pull request.PR 설명에 Closes #114, 스크린샷 추가, Create pull request.

    C · TerminalC · 터미널

    When you're curious궁금할 때

    The same sticker PR, by hand. Click a line to copy it. Uses your clean app folder.같은 스티커 PR을 직접. 줄을 누르면 복사돼요. 깨끗한 앱 폴더를 써요.

    1. cd ~/Claude/pawnote-play
    2. git fetch origin && git switch -c design/sticker-set origin/main
    3. Copy the 9 PNGs into frontend/assets/stickers/.PNG 9개를 frontend/assets/stickers/에 복사.
    4. git status
    5. git add frontend/assets/stickers && git commit -m "feat: add the Goldito sticker set"
    6. git push -u origin design/sticker-set
    7. gh pr create --title "feat: add the Goldito sticker set" --body "Closes #114"
