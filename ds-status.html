How to keep it consistent

One source per componentThe design site page is the spec; Figma is built from it by the plugin; the app follows a Figma-to-code table. No screen keeps its own copy.
Build the part, then swap screensOne PR per family (Selection, Layout, Cards). The part comes first, then every screen that hand-rolls it switches to it in the same PR.
A kit screen in the appA /dev/kit route showing every variant, like Minsik's /dev/sprites. Design QA happens there once, not per screen.
Guard railsA grep check in CI: no hex colours, font sizes or emoji in labels outside theme and the kit.

Suggested order before Oct 28
